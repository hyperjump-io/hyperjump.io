# Blog posts

Write posts in this repo, in `src/content/docs/blog/`, one Markdown file
for each post. The filename is the post's URL: `blog/<filename>/`.

Give each post frontmatter with these properties:

| Property | Description |
| --- | --- |
| `title` | The post's title. |
| `date` | The day that you publish the post. |
| `authors` | Who wrote the post. |
| `tags` | Optional. Tags for the post. |
| `excerpt` | Optional. The text that the post list shows for the post. |

Posts use the same Markdown as the docs. That includes
[links](links.md) and [code blocks](code-blocks.md).

Link to the docs for how things work. Don't update a post after you
publish it.

For how the site builds the blog, see [Blog](../components/blog.md).
