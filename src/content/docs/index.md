Tools for JSON Schema and JSON hypermedia.

- [JSON Schema](/json-schema/): validate, annotate, and lint JSON Schema.
  Looking for v1? See the [v1 README](https://github.com/hyperjump-io/json-schema/tree/v1#readme).
- [hjlint](/hjlint/): the `hyperjump` command line tool.
- [Browser](/browser/): a generic client for JSON hypermedia.
