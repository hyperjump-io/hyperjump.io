## In your code

Libraries for Node.js and browsers.

<div class="packages not-content">
  <PackageCard title="JSON Schema" href="/json-schema/" command="npm install @hyperjump/json-schema">
    A validator and linter for every dialect from draft-04 to 2020-12, and
    JSON Schema v1. Errors with positions in the JSON text, and annotations.
  </PackageCard>
</div>

## On the command line

In your terminal and in CI.

<div class="packages not-content">
  <PackageCard title="hjlint" href="/hjlint/" command="npx hjlint .">
    Lints schemas and validates JSON files against them, with the same rules
    as the library.
  </PackageCard>
</div>

</div>

The libraries the tools are built from. Each one installs and works on its
own.

<div class="packages not-content">
  <PackageCard title="Browser" href="/browser/" command="npm install @hyperjump/browser">
